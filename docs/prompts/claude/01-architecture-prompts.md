# Claude Architecture Prompts

Purpose:
- Generate high-level architecture guidance for Open Banking QE, AI-enabled test automation, and enterprise integration.

When to use:
- Designing new test platform components
- Documenting system boundaries and data flows
- Aligning AI modules with Open Banking compliance

Expected output:
- Clear architecture descriptions
- Component relationships and responsibilities
- Recommended integration patterns for Playwright, MCP, CI/CD, and reporting

Prompt examples:
- "Describe an enterprise Open Banking QE architecture with Playwright, AI scenario generation, and Allure reporting."
- "Suggest a modular architecture for MCP-enabled test automation in a CDR platform."
- "Recommend integration patterns for QA pipelines, contract validation, accessibility, and security."
