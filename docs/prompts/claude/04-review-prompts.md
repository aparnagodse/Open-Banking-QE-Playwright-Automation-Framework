# Claude Review Prompts

Purpose:
- Review architecture, documentation, and AI design decisions for quality and compliance.

When to use:
- Validating changes before design or implementation
- Reviewing documentation against Open Banking and CDR requirements
- Checking AI module proposals for risk or gaps

Expected output:
- A concise review summary
- Identified risks and recommendations
- Improvements for clarity, compliance, or security

Prompt examples:
- "Review this QE architecture for Open Banking compliance and highlight gaps."
- "Evaluate whether the AI scenario generation approach supports CDR contract validation." 
- "Assess the proposed MCP integration for security and maintainability."
