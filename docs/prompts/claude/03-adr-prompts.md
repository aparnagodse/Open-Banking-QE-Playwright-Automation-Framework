# Claude ADR Prompts

Purpose:
- Create Architecture Decision Records for design choices in the Open Banking QE platform.

When to use:
- Making technology or architecture decisions
- Documenting rationale for Playwright, MCP, AI, or reporting choices
- Capturing trade-offs and governance requirements

Expected output:
- A structured ADR with problem statement, alternatives, decision, and consequences
- Concise reasoning for each architectural decision
- Linkage to compliance, security, and CI/CD requirements

Prompt examples:
- "Draft an ADR for selecting Playwright and MCP for Open Banking QE automation."
- "Write a decision record for adopting AI-generated test scenarios and coverage analysis."
- "Create an ADR capturing the rationale for Allure reporting and GitHub Actions CI/CD."
