# Claude Accessibility & Security Prompts

Purpose:
- Generate guidance for accessibility, security, and compliance testing in Open Banking QE.

When to use:
- Defining WCAG and security test requirements
- Evaluating regulatory and privacy controls
- Generating test ideas for accessibility and threat modeling

Expected output:
- Accessibility validation scenarios and best practices
- Security test patterns and risk checks
- Compliance guidance for Open Banking, CDR, and data protection

Prompt examples:
- "List accessibility test cases for a consent management page in Open Banking." 
- "Generate security test ideas for API authentication, CSRF, and data exposure." 
- "Recommend compliance checkpoints for CDR transaction and account APIs."
