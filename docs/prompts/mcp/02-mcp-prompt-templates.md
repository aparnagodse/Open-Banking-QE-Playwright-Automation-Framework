# MCP Prompt Templates

Purpose:
- Supply reusable MCP prompt patterns for AI-assisted test creation and documentation.

When to use:
- Generating code that must follow internal guidelines
- Creating test plans from business requirements
- Producing documentation and governance artifacts

Expected output:
- Structured prompt templates for tasks and deliverables
- Context-aware instructions for the model
- Repeatable prompt design with placeholders for repo-specific details

Prompt examples:
- "Write a Playwright test file using POM and existing page classes for feature X." 
- "Generate a test plan that maps Open Banking acceptance criteria to automation scenarios." 
- "Produce release notes or documentation based on the current QE platform state."
