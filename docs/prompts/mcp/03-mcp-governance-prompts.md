# MCP Governance Prompts

Purpose:
- Define AI governance, code review, and compliance checks within MCP workflows.

When to use:
- Writing guardrails for AI-generated changes
- Generating PR review checklists and compliance summaries
- Enforcing Open Banking, security, and accessibility requirements

Expected output:
- Governance rules and review criteria
- Compliance checkpoints for AI-assisted code
- Suggested labels, process steps, and mitigation actions

Prompt examples:
- "Create an AI governance checklist for Open Banking QE changes." 
- "Generate a PR review template that includes accessibility, security, and contract validation." 
- "Summarize risks for AI-generated Playwright tests and recommended review steps."
