# MCP Context Prompts

Purpose:
- Provide structured context for the Model Context Protocol during AI-assisted code generation.

When to use:
- Initializing MCP sessions for repository-aware prompts
- Providing project structure, conventions, and domain context
- Ensuring AI output matches enterprise guidelines

Expected output:
- A concise project context summary
- List of architecture, test, and governance constraints
- Clear guidance on coding style and folder organization

Prompt examples:
- "Summarize the Open Banking QE repo context for MCP with Playwright and Allure." 
- "Provide the MCP model with project conventions for ES6 module tests and POM." 
- "Define the AI assistant context for compliance-heavy Open Banking test automation."
