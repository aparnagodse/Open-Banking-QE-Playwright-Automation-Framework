# Reporting Prompts

Purpose:
- Generate documentation, status reports, and summary artifacts for the AI QE platform.

When to use:
- Creating README content, architecture summaries, or release notes
- Drafting project status updates for stakeholders
- Producing defect summaries and test-run insights

Expected output:
- Structured documentation with clear headings and governance guidance
- Executive summaries and technical update notes
- Actionable recommendations for next steps and risk areas

Prompt examples:
- "Write a project status report for the Open Banking QE automation platform." 
- "Draft a README section describing the AI prompt library and governance model." 
- "Create a defect summary and remediation plan for the latest regression run."
