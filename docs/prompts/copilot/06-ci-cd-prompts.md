# Copilot CI/CD Prompts

Purpose:
- Generate GitHub Actions workflows, CI checklists, and automated test pipeline definitions.

When to use:
- Writing new workflow YAML files for regression, accessibility, performance, or contract validation
- Defining CI gates for AI-generated code
- Creating pipeline documentation and step definitions

Expected output:
- Workflow file templates with jobs, runners, and steps
- CI guardrails for Playwright, reporting, and Allure generation
- Compliance and review steps for PR validation

Prompt examples:
- "Generate a GitHub Actions workflow for Playwright regression tests and Allure report publishing." 
- "Create a CI gate checklist for AI-assisted Open Banking QE changes." 
- "Write a scheduled accessibility and performance workflow for an enterprise QA platform."
