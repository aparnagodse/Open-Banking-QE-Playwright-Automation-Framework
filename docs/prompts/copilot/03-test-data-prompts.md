# Copilot Test Data Prompts

Purpose:
- Generate realistic test data and fixture values for Open Banking scenarios.

When to use:
- Creating account, transaction, and consent test data
- Producing synthetic data for contract and reconciliation tests
- Simulating regulatory and privacy-safe datasets

Expected output:
- Structured test data objects and JSON fixtures
- Valid input sets for positive and negative cases
- Data variants for boundary conditions and compliance checks

Prompt examples:
- "Generate Open Banking account and transaction test data for regression tests." 
- "Create synthetic consent lifecycle fixtures with valid and expired states." 
- "Produce sample API response data for CDR account list and transaction history."
