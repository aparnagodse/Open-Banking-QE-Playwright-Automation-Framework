# Copilot Test Scenario Prompts

Purpose:
- Generate structured test scenarios for UI, API, accessibility, performance, and security.

When to use:
- Creating new regression or contract tests
- Expanding coverage for Open Banking workflows
- Producing edge case and negative-case scenarios

Expected output:
- Scenario names, steps, and expected outcomes
- Variants for happy path, error path, and compliance validation
- Prioritized test ideas aligned to business requirements

Prompt examples:
- "Generate test scenarios for Open Banking consent lifecycle and account access." 
- "List API contract validation scenarios for CDR accounts and transactions endpoints." 
- "Create accessibility and keyboard navigation test scenarios for a login flow."
