# Copilot Locator and Page Object Prompts

Purpose:
- Generate or refine Playwright locators, page object classes, and POM interactions.

When to use:
- Building new page object models
- Choosing robust selectors for unstable UI pages
- Converting manual flows into reusable page methods

Expected output:
- Recommended locator strategies and data-test attribute patterns
- Page object class templates with methods and locators
- Business-focused interaction flows for reuse in tests

Prompt examples:
- "Create a Playwright page object for a login page with data-test selectors." 
- "Suggest robust locator fallbacks for a dynamic account dashboard." 
- "Generate helper methods for form filling, navigation, and validation in POM."
