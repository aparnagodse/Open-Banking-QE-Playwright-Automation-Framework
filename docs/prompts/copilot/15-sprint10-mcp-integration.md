# Sprint 10 — MCP Integration Prompt

Purpose

- Guide Copilot to scaffold MCP integration artifacts: MCP config, agent stubs, and Playwright agent connectors.

When to use

- Use when integrating Playwright MCP server and exposing controlled browser actions to AI agents in a new repository.

Copilot execution prompt

You are an automation infrastructure engineer. Create TypeScript/JS stubs and configuration for MCP server integration: a `playwright-mcp-config.json` example, agent connector interfaces, and safe stubs for agent actions (navigate, click, assert, screenshot). Keep implementations as interfaces and method stubs; do not enable remote execution or include credentials. Emphasize human review gates for any autogenerated specs.

Expected output

- `playwright-mcp-config.json` example (if not present)
- `src/ai/mcpConnector.ts` stub exporting interfaces for MCP actions
- `docs/mcp-integration.md` guidance for safe MCP deployment and review gates

Verification checklist

- [ ] MCP config example present and non-sensitive
- [ ] Agent connector stubs are typed and non-executable
- [ ] Documentation highlights review gating and security considerations
